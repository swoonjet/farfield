# FarField

An endless console for listening and making music: live microphones around the world, sound archives foraged by birds, grains, rooms, tides, a melody, a sequencer and a bass line, all in one key.

Live at https://jontoews.com/farfield/

This repo holds only the built page. The source is the Control Room project (`~/Projects/control-room`); publish from there with `scripts/publish.sh`.
